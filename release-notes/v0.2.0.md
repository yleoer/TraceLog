# TraceLog v0.2.0

本版本将桌面应用从 Go/Wails 重写为 Rust + Tauri 2，沿用 Vue 3 + Naive UI 工作界面，仅支持 Windows amd64。

## 架构重构

- 使用 Cargo workspace、Tauri 原生 IPC、Rust 业务层与 SQLite 数据层，移除 Go/Wails 源码、生成绑定和旧独立后端。
- 前端业务统一通过原生客户端调用，保留现有工作界面。

## 功能迁移

- 迁移 Issue、标签、工作周期、评论、TODO、临时需求、每日记录和今日工作流。
- 迁移 ISO 周视图、周报草稿、多周期月度甘特图、SQLite FTS 全局搜索，以及 Markdown、JSON 和含图片的 ZIP 导出。
- 迁移 Jira 导入预览与刷新，支持完整状态历史分页、重开周期、Release Requested 字段及 ADF 转 Markdown；刷新保留用户备注和自定义标签。
- 迁移 Tempo 周工时缓存、主动刷新、单日及日期范围提交，逐日报告成功和失败。
- 迁移 OpenAI 兼容服务和 DeepSeek 的 Issue 简述、周总结及自定义提示词。
- 迁移 Markdown 图片上传、读取和未引用图片清理，接入原生剪贴板、外部链接与窗口控制。

## 升级与发布

- 使用 Tauri 官方签名升级插件与用户级 NSIS 安装器，下载并验签成功后安装和重启；移除手工更新助手。
- GitHub Actions 在分支推送时检查 Rust 和前端，标签发布时生成 Windows x64 安装器、签名文件与 `latest.json`，上传至草稿后统一公开。
- 升级私钥由 CI Secret 提供，应用使用时无需配置私钥；后续版本继续使用同一签名密钥。

## 数据兼容

- 沿用旧版数据和设置路径，支持原有数据目录、时区、Jira 和 AI 环境变量。
- 首次打开旧库时，先一致性备份数据库、设置和图片，再在事务内调整结构并回填搜索索引；重复启动不会重复转换。
- 保留设置原子保存、空凭据保留原值，以及网络请求期间不占用数据库锁的处理。

## 问题修复

- 修复历史周范围遗漏，以及毫秒和 RFC3339 时区偏移造成的日、周时间边界错误。
- Jira 可选字段元数据接口发生非认证 HTTP 错误时使用 `fixVersions` 继续导入，认证错误仍正常报告。

## 维护精简

- 按个人单机使用场景精简通用并发冲突框架、额外任务锁、IPC 等待队列及复杂验收工具，保留核心业务的快速测试。
- 更新开发、构建、CI 签名配置和旧版迁入文档。

## 首次从 Wails 版迁入

1. 退出旧版，独立备份整个 `%APPDATA%/TraceLog`；自定义过数据目录时备份实际目录，包含数据库、设置和图片。
2. 卸载旧版系统级安装，安装本版本的用户级 NSIS 安装器，并使用同一个 Windows 用户运行。
3. 首次启动前确认原数据目录完整；若卸载删除了数据，先从独立备份恢复。新版会自动创建 `backups/pre-rust-*` 备份并转换旧库。
4. 核对 Issue、评论、TODO、临时需求、周报和图片。迁入成功后，后续 Tauri 版本可在设置页签名升级。

Wails 到 Tauri 需要手动迁入一次。请勿同时运行两个版本写同一数据目录。详细步骤见 [README](https://github.com/yleoer/TraceLog/blob/v0.2.0/README.md#从-wails-版迁入)。
